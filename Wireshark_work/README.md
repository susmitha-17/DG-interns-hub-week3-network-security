# Wireshark Work

This folder contains the Wireshark-based network traffic analysis performed as part of the Week 3 Cybersecurity Assessment.

## Activities Performed

- Network traffic capture
- DNS traffic analysis
- TCP and UDP traffic analysis
- ICMP traffic analysis
- ARP traffic analysis
- Nmap traffic observation using Wireshark
- Identification of important packets and network communication patterns

## Traffic Analysis

The captured traffic was analyzed using Wireshark display filters such as:

- `dns`
- `tcp`
- `udp`
- `icmp`
- `arp`
- `tcp.flags.syn == 1`
- `tcp.flags.reset == 1`

## Evidence

The screenshots and packet capture files in this folder provide evidence of the traffic analysis performed in the authorized virtual lab environment.

## Tools Used

- Wireshark
- Windows 11 Host
- Ubuntu Desktop Virtual Machine
- VirtualBox
