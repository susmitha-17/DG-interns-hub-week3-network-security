# System Hardening

This folder documents the security hardening measures applied to the Ubuntu virtual machine after the vulnerability assessment.

## Hardening Measures

- Enabled UFW firewall
- Disabled the Avahi/mDNS service
- Applied available Ubuntu system updates
- Verified the system after hardening using Nmap and local service checks

## Before and After Evidence

The Before folder contains evidence collected before hardening.

The After folder contains evidence collected after the security controls were applied.

## Objective

The objective was to reduce the attack surface and improve the security posture of the authorized Ubuntu lab system.
