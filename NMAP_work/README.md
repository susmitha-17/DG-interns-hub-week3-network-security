# NMAP Work

This folder contains the Nmap-based network security assessment conducted as part of the Week 3 Cybersecurity Assessment.

## Activities Performed

- Network configuration and host discovery
- Basic Nmap scanning
- Service and version detection
- Operating system detection
- TCP SYN scanning
- UDP top-port scanning
- Vulnerability assessment using Nmap NSE scripts
- Analysis and documentation of discovered network services

## Evidence

The associated screenshots provide evidence of the Nmap scans and their results performed in the authorized virtual lab environment.

## Target

Ubuntu Desktop VM: `192.168.56.101`

## Tools Used

- Nmap
- Windows 11 Host
- Ubuntu Desktop Virtual Machine
- VirtualBox
